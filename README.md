# KAZA V1
MVP immobilier HTML + CSS + JavaScript Vanilla + Supabase.

Contenu :
- Accueil + recherche
- Inscription / connexion
- Publication d'annonce
- Fiche logement
- Dashboard bailleur
- Un seul fichier CSS : css/style.css
- Schéma Supabase : supabase_schema.sql
- Aucun Python / FastAPI

Installation :
1. Ouvrir Supabase > SQL Editor.
2. Exécuter supabase_schema.sql.
3. Vérifier js/supabase.js.
4. Lancer le projet avec VS Code Live Server ou un autre serveur statique.
5. Ouvrir index.html.

Important : seule la clé publique anon doit être utilisée dans le navigateur. Ne jamais exposer une clé service_role.
